## Existing alternatives and their gaps

| Alternative | Type | Price range | Gap / weakness |
|---|---|---|---|
| Firecrawl | SaaS API | Free tier; $16–$333/mo (or pay-per-use) | No native MCP tool for Claude Code / Cursor; anti-bot bypass inconsistent; not optimized for token-minimal output for LLM agents specifically |
| Jina Reader (r.jina.ai) | SaaS API / URL prefix | Free tier; $0.02/1k tokens on paid | Returns Markdown but no MCP manifest; JS rendering partial; rate limits on free tier hit frequently by agent loops |
| Browserless | Headless browser API | $24–$650/mo | Raw rendering only — no content cleaning/compression; dev must build the summarization layer themselves |
| ScrapingBee | Scraping API | $49–$599/mo | Same as Browserless: returns full HTML; no LLM-aware compression; not agent-ergonomic |
| Claude Code built-in web_fetch | Native tool | Included in API cost | Fails on JS-rendered pages entirely; returns raw HTML (68k–353k tokens) on static pages; no anti-bot capability |
| DIY Jina prefix workaround | Manual config | Free | Brittle; breaks on auth-gated pages; no anti-bot; users must maintain config manually; not portable across agent setups |
| Status quo (ignore it) | Behavioral | "Free" | Developers either blow their context window or skip web research steps entirely, degrading agent output quality |

## Estimated TAM / SAM

### Israel

- **TAM:** Anthropic reported ~1M+ active Claude API developers globally (2025); Israel's developer community is ~130,000 active software developers (CBS 2024), with AI/LLM adoption estimated at ~8–12% for API-level usage. Conservative estimate: 10,000 Israeli developers on paid Claude/Cursor plans doing agentic work. If 30% face this pain frequently enough to pay: **3,000 potential customers × USD 20/mo ACV = USD 720K/year TAM (Israel)**.
- **SAM (reachable in 12 months):** Israeli AI developer communities (Slack groups, Tel Aviv AI meetups, LinkedIn Israel Tech) are tightly networked. Realistic reach in 12 months: 300–500 paying customers × USD 20/mo = **USD 72K–120K ARR (Israel SAM)**.

### Global

- **TAM:** Anthropic ~1M+ Claude API developers; Cursor reported 500K+ users (2025); conservative overlap estimate of 1.5M developers on paid AI coding agent plans globally. 25% face token-waste pain severely enough to pay for a solution: **375,000 customers × USD 20/mo = USD 90M/year TAM (Global)**.
- **SAM (reachable in 12 months):** Via HN Show HN, Claude Discord, X/Twitter developer audience, and Product Hunt launch — realistically reachable and convertible: **2,000–5,000 paying customers × USD 20/mo = USD 480K–1.2M ARR (Global SAM in Year 1)**.
