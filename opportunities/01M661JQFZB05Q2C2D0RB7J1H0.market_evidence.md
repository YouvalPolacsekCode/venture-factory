## Existing alternatives and their gaps

| Alternative | Type | Price range | Gap / weakness |
|---|---|---|---|
| Langfuse | SaaS (open-source + cloud) | $0–$299/mo | Logs and traces LLM calls but does not run scheduled canary probes against provider APIs; regression detection requires user to build their own eval pipeline |
| Braintrust | SaaS | $0–$500+/mo | Eval harness for teams, but eval runs are manual/CI-triggered, not continuous background canaries |
| PromptLayer | SaaS | $0–$199/mo | Request logging and versioning; no proactive quality monitoring or provider-level regression alerting |
| Helicone | SaaS | $0–$200+/mo | Proxy-based cost and latency monitoring; does not score output quality or alert on model degradation |
| DIY internal evals | DIY | Engineering time only | Requires dedicated MLOps effort; not feasible for teams <10 engineers; no alerting built in |
| Status-page monitoring (Statuspage.io) | DIY | $0–$100/mo | Monitors uptime, not output quality; a model can be "up" and silently worse |
